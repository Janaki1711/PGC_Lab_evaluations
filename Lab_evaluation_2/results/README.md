# Results provenance

Historical measurements from the original RTX 5060 Ti machine were supplied in the project notes. The original raw repeated-run logs and complete per-run records are not available in this reconstruction. Therefore no fabricated per-run data or standard deviations are included.

Reconstructed programs must be rebuilt and rerun to produce new measurements. Keep new runs separate from historical values and record GPU, driver, CUDA toolkit, compiler, input size, distribution, repetitions, and timing boundaries.
